## 🎯 About The Project

The **Data Science Job Market Dashboard** analyzes job-posting data to provide insights into roles, skills, salaries, locations and companies.

The project follows an end-to-end data analytics workflow:

**Data Cleaning → EDA → SQL Analysis → Visualization → Streamlit Dashboard → Deployment**

---

## ✨ Features

* 📊 Job market overview
* 💼 Job role analysis
* 🔧 Skill demand analysis
* 💰 Salary analysis
* 📍 Location-wise job analysis
* 🏢 Company analysis
* 📈 Interactive Plotly charts
* 🔍 Role-based insights
* 🌐 Live Streamlit deployment

## 📌 Key Insights

The dashboard helps answer questions such as:

* Which job roles are most in demand?
* Which skills are most frequently required?
* Which locations have the highest number of jobs?
* How does salary vary across different roles?
* Which companies are hiring the most?
* How does company size affect salary?
* Which industries offer more opportunities?

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/AyushChaudhary06/data-science-job-market.git
cd data-science-job-market
```

### 2. Create virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
streamlit run app/app.py
```
